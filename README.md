## 📋 Overview

This repository contains coursework and practice implementations focused on **core data structures and algorithms in C**. The goal is to demonstrate hands-on work with pointers, memory management, traversal logic, search methods, and tree balancing concepts.

---

## 📁 Files

<div align="center">

| File | Description |
|------|-------------|
| 📂 `linked_list_order_queue.c` | Linked list implementation for ordered queue-style operations |
| 📂 `priority_queue_array.c` | Priority queue implementation using an array-based approach |
| 📂 `bst_to_avl_tree.c` | Binary search tree logic and AVL tree balancing concepts |
| 📂 `stack_brace_validator.c` | Stack-based validation for braces and delimiters |
| 📂 `binary_search_iterative.c` | Iterative binary search implementation |
| 📂 `binary_search_recursive.c` | Recursive binary search implementation |
| 📂 `linked_list_order_system.c` | Linked-list-based ordering and record management workflow |
| 📂 `priority_queue_heap.c` | Heap-style priority queue implementation |
| 📂 `avl_tree_preorder_traversal.c` | AVL tree traversal logic with preorder traversal |

</div>
