# Data Structures in C

Collection of C implementations covering stacks, linked lists, binary search, priority queues, BSTs, and AVL trees.

## Overview

This repository contains coursework and practice implementations focused on core data structures and algorithms in C. The goal of this repo is to show hands-on work with pointers, memory management, traversal logic, search methods, and tree balancing concepts.

## Files

- `linked_list_order_queue.c` — linked list implementation for ordered queue-style operations.
- `priority_queue_array.c` — priority queue implementation using an array-based approach.
- `bst_to_avl_tree.c` — binary search tree logic and AVL tree balancing concepts.
- `stack_brace_validator.c` — stack-based validation for braces / delimiters.
- `binary_search_iterative.c` — iterative binary search implementation.
- `binary_search_recursive.c` — recursive binary search implementation.
- `linked_list_order_system.c` — linked-list-based ordering or record-management workflow.
- `priority_queue_heap.c` — heap-style priority queue implementation.
- `avl_tree_preorder_traversal.c` — AVL tree traversal logic with preorder traversal.

## Concepts Covered

- Stacks
- Linked lists
- Priority queues
- Binary search
- Binary search trees
- AVL trees
- Recursive vs iterative algorithms
- Traversal and ordering logic
- Pointer-based programming in C

## Why this repo exists

I created this repository to organize and present foundational C programming and data structure work in a cleaner, more professional format for future projects, interviews, and technical growth.
